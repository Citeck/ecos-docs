Конфигурация AI инструментов
===============================

Раздел описывает AI-инструменты платформы Citeck: настраиваемых агентов на базе LLM и модуль записи совещаний.

:ref:`Пользовательские AI-агенты <user-agents>` — конфигурируемые сущности с системным промптом, набором инструментов и выбранным :ref:`LLM-провайдером <AI_assistant_config>`. Агенты работают в двух режимах: stateless (однократный вызов из :ref:`BPMN-процессов <process_bpmn>`) и stateful (многоходовой диалог в :ref:`AI Assistant UI <AI_assistant>`). Администратор создаёт агентов через **Admin > AI Agents**, разработчик подключает собственные инструменты, реализуя интерфейс ``CiteckAiTool``.

:ref:`Модуль записи совещаний <call-recording-module>` захватывает аудио из браузерной вкладки и микрофона через :ref:`Chrome-расширение <citeck_browser_plugin>`, транскрибирует его с помощью GigaAM и автоматически формирует резюме через LLM. Результат сохраняется как ECOS-активность типа ``meeting-activity`` или ``call-activity``. Модуль доступен начиная с версии **1.11.0**.
