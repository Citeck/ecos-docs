.. _developer_tools:

Инструменты разработчика
==========================

Раздел содержит описание инструментов, предназначенных для разработки и отладки на платформе Citeck.

.. grid:: 1
   :gutter: 2

   .. grid-item-card:: Консоль разработчика
      :link: developer_console
      :link-type: ref

      Встроенный инструмент для выполнения JavaScript-кода прямо в браузере с отображением результатов в реальном времени. Доступна администраторам из раздела администрирования.

   .. grid-item-card:: Плагин для IntelliJ IDEA
      :link: intellij_idea_plugin
      :link-type: ref

      Расширение для IDE, которое ускоряет работу с проектами и артефактами платформы: поддерживает автодополнение, деплой артефактов и навигацию по конфигурациям прямо из редактора.

   .. grid-item-card:: Браузерное расширение Citeck
      :link: citeck_browser_plugin
      :link-type: ref

      Chrome-расширение для разработчиков и администраторов: умная строка поиска по действиям, инструменты для работы с записями и вкладка DevTools для мониторинга Records API.
