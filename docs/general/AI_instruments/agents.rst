.. _ai-agents:

AI-агенты
===============================

Раздел объединяет документацию по AI-агентам платформы: модель данных агента, режимы выполнения, доступные инструменты, порядок создания — и архитектуру их выполнения — движки, маршрутизацию, конвейер планирования и исполнения, точки участия человека.

.. grid:: 1
   :gutter: 3

   .. grid-item-card:: Пользовательские AI-агенты
      :link: user-agents
      :link-type: ref

      Конфигурируемые сущности с системным промптом, набором инструментов и :ref:`LLM-провайдером <AI_assistant_config>`. Режимы: stateless (вызов из :ref:`BPMN <process_bpmn>`) и stateful (диалог в :ref:`AI Assistant UI <AI_assistant>`). Создаются через **Admin > AI Agents**, инструменты — через интерфейс ``CiteckAiTool``.

   .. grid-item-card:: Архитектура выполнения AI-агентов
      :link: ai-architecture
      :link-type: ref

      Движки выполнения (``TOOL_LOOP`` и ``CONFIG``), маршрутизация запросов, конвейер планирования и исполнения многоартефактных запросов, сводный перечень точек участия человека (HITL), области публикации артефактов с локальными копиями и ограничения выполнения.
