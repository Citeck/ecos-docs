AI-агенты
===============================

**AI-агент** — настраиваемая сущность платформы, которая с помощью языковой модели самостоятельно выполняет пользовательские задачи: анализирует запрос, обращается к данным и инструментам платформы (записи, журналы, база знаний, REST API и т.д.), формирует план действий и выполняет его, при необходимости запрашивая подтверждение у человека. Агенты нужны для автоматизации рутинных и аналитических операций, которые иначе требовали бы ручной работы пользователя в интерфейсе или написания кода, — например, поиска и обработки информации, заполнения и проверки данных, подготовки ответов и документов на основе базы знаний.
