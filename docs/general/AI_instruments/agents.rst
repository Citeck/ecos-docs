AI-агенты
===============================

Раздел объединяет документацию по AI-агентам платформы: модель данных агента, режимы выполнения, каталог доступных инструментов, преднастроенные агенты, подключение базы знаний, порядок создания — и архитектуру их выполнения — движки, маршрутизацию, конвейер планирования и исполнения, точки участия человека.

.. grid:: 1
   :gutter: 3

   .. grid-item-card:: Конфигурация AI-агентов
      :link: user-agents
      :link-type: ref

      Описание модели данных агента, каталога операционных и конфигурационных инструментов, подключение базы знаний и REST API, создание пользовательских агентов.

   .. grid-item-card:: Архитектура выполнения AI-агентов
      :link: ai-architecture
      :link-type: ref

      Движки выполнения (``TOOL_LOOP`` и ``CONFIG``), маршрутизация запросов, конвейер планирования и исполнения многоартефактных запросов, сводный перечень точек участия человека (HITL), области публикации артефактов с локальными копиями и ограничения выполнения.
