Настройка RAG-сервиса
========================================

Микросервис семантического поиска и индексации документов для платформы Citeck на базе RAG (Retrieval-Augmented Generation).

Сервис индексирует данные из **Citeck-записей** и GitLab-репозиториев, строит векторные представления с помощью OpenAI Embeddings и обеспечивает семантический поиск через Qdrant.

Возможности:

- **Семантический поиск** по содержимому документов Citeck и исходному коду GitLab
- **Workspace-изоляция** — отдельные Qdrant-коллекции для каждого рабочего пространства Citeck
- **Индексация Citeck-записей** — извлечение контента из атрибутов, файлов и метаданных записей
- **Индексация GitLab** — сканирование репозиториев с поддержкой инкрементальной синхронизации через Commits API
- **Event-driven индексация** — автоматическое обновление индекса при создании, изменении и удалении записей
- **Контроль доступа** — фильтрация результатов поиска по правам пользователя и membership в workspace
- **MCP-сервер** — интеграция с Claude Code и другими AI-моделями через Model Context Protocol
