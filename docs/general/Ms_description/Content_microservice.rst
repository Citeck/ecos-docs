Content микросервис
====================================

.. note::

    Доступно только в Enterprise версии.

**ECOS-content** — микросервис для хранения файлов во внешних хранилищах. Он позволяет использовать несколько конфигураций хранилищ и направлять контент разных типов объектов в разные хранилища. В микросервисе реализована работа с S3-совместимыми хранилищами, включая потоковую загрузку и загрузку чанками.

.. tip::

    1. Создайте :ref:`конфигурацию хранилища <content_new_config>` и выберите её :ref:`по умолчанию <content_deployment>` или :ref:`для конкретного типа <type_content_storage>`. Если маршрут загрузки использует системный тип **temp-file**, проверьте также его настройки хранилища с учётом версии ecos-model и используемой формы.

    2. При массовой загрузке файлов учитывайте ограничения S3, маршрута загрузки и доступное место для временных файлов. Возможности сервиса и настройки размера файла описаны в разделе :ref:`конфигурации хранилищ <content_new_config>`.

    3. На стандартной форме **doclib-file** настроен ряд параметров для корректной загрузки файлов. Если будет использоваться кастомная форма, то нужно учитывать настройки этой формы, в частности обязательности контента и задание конфигурации максимального размера файла на форме. См. :ref:`подробно <new_document_library>`
