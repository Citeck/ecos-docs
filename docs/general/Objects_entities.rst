.. _objects_entities:

Объекты и сущности
====================

Раздел описывает базовые концепции платформы Citeck, с помощью которых строится и расширяется функциональность системы.

.. grid:: 1
   :gutter: 3

   .. grid-item-card:: Артефакты
      :link: artifacts
      :link-type: ref

      Конфигурационные объекты платформы (типы данных, формы, журналы, процессы и др.), хранящиеся в форматах JSON/YAML/XML и разворачиваемые в систему через интерфейс или средства автоматизации.

   .. grid-item-card:: Патчи
      :link: patches
      :link-type: ref

      Разовые операции миграции данных и конфигурации, выполняемые автоматически или вручную при запуске системы. Реализованы как артефакты типа ``app/patch``.

   .. grid-item-card:: Аспекты
      :link: aspects
      :link-type: ref

      Механизм расширения типов данных без их изменения: добавляют атрибуты и поведение к сущностям, могут переиспользоваться между несколькими типами.
