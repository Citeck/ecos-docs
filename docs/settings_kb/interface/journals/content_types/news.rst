Новости
==============

.. contents::
   :depth: 3

**Журнал «Новости»** предназначен для публикации анонсов и новостей компании. Они отображаются сотрудникам непосредственно в рабочих пространствах через виджет :ref:`Новости <widget_news>`.

Журнал основан на типе данных :ref:`Публикация <publication>`. Добавьте журнал **Новости** в меню для перехода к списку записей. Состав виджета определяется отдельно: он запрашивает записи выбранного типа (по умолчанию ``news``) в соответствующих рабочих пространствах и показывает до трёх последних записей по времени создания. Пункт меню не является условием этого запроса; записи также должны быть доступны пользователю.
