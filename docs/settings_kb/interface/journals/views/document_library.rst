.. _document_library:

Библиотека документов (Document Library)
==========================================

.. contents::
    :depth: 3

**Библиотека документов (Document Library)** — раздел для хранения и организации файлов в виде дерева папок, похожий на проводник Windows. Здесь вы можете загружать документы, создавать папки, а также перемещать и удалять файлы.

Библиотека подключается к меню через специальный элемент **DocLib**. Стандартный способ настройки — создать тип данных на основе **Файл библиотеки документов** с наследованием формы и действий. Возможность работы типа в режиме библиотеки определяется аспектом ``doclib``. См. раздел :ref:`Создание библиотеки документов <new_document_library>`.

Доступность создания и редактирования документов, OnlyOffice, блокировки и других действий зависит от прав пользователя, конфигурации действий и подключённых серверных сервисов.

.. image:: _static/doclib/DocLib_1.png
   :width: 700
   :align: center

На компьютере дерево папок отображается по умолчанию. Чтобы свернуть его, нажмите **(1)**. Состояние сворачивания сохраняется в браузере (``docLibTreeCollapsed``). На мобильном устройстве дерево изначально скрыто и открывается отдельной кнопкой:

.. image:: _static/doclib/DocLib_2.png
   :width: 700
   :align: center

Режим отображения восстанавливается из сохранённого выбора браузера (``docLibDisplayMode``). Если представление ещё не выбрано, на компьютере отображается список, а на мобильном устройстве — плитки. Для переключения между списком и плитками используйте кнопку **(2)**:

.. image:: _static/doclib/DocLib_2_1.png
   :width: 700
   :align: center

Для обновления данных нажмите **(3)**.

.. image:: _static/doclib/DocLib_3.png
   :width: 700
   :align: center

1. Папка, которую вы выбрали, подсвечивается среди остальных **(1)**.
2. Для папок используется отдельная иконка, а иконка файла определяется по расширению его отображаемого названия **(2)**. Примеры форматов:

   - Microsoft Word (doc, docx);
   - Microsoft Excel (xls, xlsx);
   - Microsoft Powerpoint (ppt, pptx);
   - Adobe Acrobat (pdf);
   - Файлы изображений (jpg, bmp, png, gif, tif);
   - OpenOffice / LibreOffice (odf);
   - Файл сообщения из электронной почты (.msg).

   Для нераспознанного расширения используется общая иконка файла.

3. Над журналом вы увидите название текущей раскрытой папки **(3)**.
4. Нажмите **(4)**, чтобы создать документ, загрузить файл или создать папку, либо перетащите файл в область библиотеки. См. ниже раздел :ref:`Создание папки / Загрузка файла <doclib_create_upload>`.
5. Используйте поиск **(5)**, чтобы найти документ в выбранной папке и её вложенных папках. При непустом поисковом тексте запрос выполняется рекурсивно.
6. Наведите курсор на файл или папку, чтобы увидеть доступные действия **(6)**. См. ниже раздел :ref:`Действия с элементом <doclib_item_actions>`.
7. Одиночный клик выделяет элемент. Двойной клик открывает папку или карточку файла. Для просмотра файла также можно воспользоваться доступным действием просмотра. См. ниже раздел :ref:`Карточка файла <doclib_file_card>`.

Перемещение файлов и папок
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Перетащите файл или папку на папку назначения в списке, плитках или дереве. Корень библиотеки также может быть целью переноса. За один такой перенос перемещается перетаскиваемый элемент, независимо от количества выделенных записей.

Нельзя переместить папку в саму себя или в её потомка. При совпадении имени в папке назначения потребуется разрешить конфликт имён.

.. image:: _static/doclib/move_file.png
   :width: 600
   :align: center

Групповые действия с файлами и папками
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Для выбора нескольких элементов используйте **Ctrl** (или **Cmd** на macOS). **Shift** добавляет диапазон от последнего нажатого элемента в текущем списке. На мобильном устройстве касание добавляет элемент в выбор или исключает его.

При выборе двух и более элементов появляется панель групповых действий **(1)**. Её состав зависит от действий, доступных для выбранных записей; часть команд может находиться в дополнительном меню:

.. image:: _static/doclib/group_actions.png
   :width: 600
   :align: center

Чтобы снять выделение, нажмите **(2)**, клавишу **Escape** или пустую область списка. Повторный обычный клик по единственному выбранному элементу также снимает выделение.

Создание библиотеки документов
---------------------------------

1. Создайте новый :ref:`тип данных <data_types_main>`.
2. Удалите **Форму по умолчанию** **(1)**.
3. На вкладке **«Основное»** укажите **id** и **Имя** **(2)**.
4. В качестве родителя выберите **«Файл библиотеки документов»** **(3)**.
5. Установите чекбокс **«Наследовать форму»** **(4)**.

Проверьте, что для созданного типа включено наследование действий и формы родителя. Аспект ``doclib`` включает режим библиотеки; в стандартной конфигурации текущий тип используется для файлов, а ``doclib-directory`` — для папок. В расширенной конфигурации аспекта можно задать другие типы файлов и папок.

.. image:: _static/doclib/DocLib_10.png
   :width: 600
   :align: center

.. dropdown:: Кастомная форма библиотеки документов. Компонент File component
   :color: secondary

   В стандартной форме ``doclib-file-form`` поле ``_content`` обязательно; максимальный размер в настройках поля — ``500GB``. Это клиентская настройка, а не гарантия допустимого размера загрузки: серверные сервисы и инфраструктура могут вводить меньшие ограничения.

   Если вы используете :ref:`кастомную форму <auto_form_change>`, сохраните обязательность поля с контентом и задайте максимальный размер с учётом ограничений вашего стенда.
