Типы контента
================

Платформа Citeck поддерживает специализированные типы контента, расширяющие возможности журналов для работы с публикациями, новостями и внутренней документацией.

.. grid:: 1
   :gutter: 3

   .. grid-item-card:: Публикация
      :link: publication
      :link-type: ref

      Управление контентом с поддержкой черновиков, версионирования и публикации записей.

   .. grid-item-card:: Новости
      :link: news
      :link-type: ref

      Виджет и журнал для публикации анонсов в рабочих пространствах.

   .. grid-item-card:: База знаний
      :link: wiki_base
      :link-type: ref

      Ведение внутренней базы знаний в рабочих пространствах.
