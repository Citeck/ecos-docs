Типы контента
================

Платформа Citeck поддерживает специализированные типы контента, расширяющие возможности журналов для работы с публикациями, новостями и внутренней документацией.

Типы, формы и правила создания записей поставляются серверными приложениями. Отображение записей в виджетах зависит от их конфигурации и прав пользователя: например, виджет новостей запрашивает записи выбранного типа и рабочих пространств, независимо от наличия журнала в меню.
