Виджет «Штрих-код»
======================

Ключ ``barcode``

Виджет отображает изображение штрихкода по значению атрибута документа. Он используется на дашборде карточки документа (``Case-details``).

При открытии виджет запрашивает изображение автоматически. Если оно ещё не получено, доступна кнопка **«Сгенерировать»**. Кнопка **«Сгенерировать новый»** повторно получает изображение по текущим данным документа; новый номер документу при этом не присваивается.

Кнопка **«Распечатать»** открывает PDF со штрихкодом в новой вкладке или окне браузера. Для печати используйте средства браузера или PDF-просмотрщика. При ошибке получения изображения виджет показывает сообщение.

Источник значения и формат
----------------------------------------

Для документов, обслуживаемых сервисом ``transformations``, по умолчанию используется атрибут ``_docNum`` и формат ``CODE_128``. Значение читается как текст; допустимое содержимое зависит от выбранного формата кодирования.

Другой источник и формат задаются в конфигурации аспекта **«Имеет штрих-код»** (``barcode``) типа данных:

* ``attribute`` — атрибут со значением для кодирования;
* ``textAttribute`` — атрибут подписи под кодом. Если не задан, используется значение из ``attribute``;
* ``format`` — формат, например ``CODE_128`` или ``QR_CODE``.

Пример конфигурации типа с атрибутом ``registrationNumber``:

.. code-block:: yaml

    aspects:
      - ref: emodel/aspect@barcode
        config:
          attribute: registrationNumber
          textAttribute: registrationNumber
          format: CODE_128

Настройки виджета
-----------------

В настройках доступны условие показа кнопки **«Сгенерировать новый»**, поле **«Тип кода»** и параметры печати: **«Масштаб»** в процентах, отступы слева, справа, сверху и снизу в миллиметрах. Для сохранения нажмите **«Готово»**, для выхода без сохранения — **«Отмена»**.

.. note::

   В текущей форме представлен тип ``Code-128``. Для современного документа фактический формат определяется аспектом типа данных.

   Масштаб и четыре отступа из формы не передаются в современный путь печати через ``transformations`` и не изменяют его результат. Эти параметры используются в отдельном пути печати для документов Alfresco.
