Виджет «Веб-страница»
===============================================

Ключ ``web-page``

Виджет отображает веб-страницу по адресу, заданному в настройках. Страница открывается во встроенном окне (``iframe``); ресурс должен разрешать такое встраивание.

Если адрес ещё не задан, нажмите **«Настроить»**. Для изменения сохранённых параметров откройте настройки в меню виджета.

Заполните оба обязательных поля:

* **«Заголовок виджета»** — название, отображаемое над страницей.
* **«URL-адрес ресурса»** — полный адрес страницы с протоколом, например ``https://example.org/page``.

Нажмите **«Готово»**, чтобы сохранить параметры и открыть страницу, или **«Отмена»**, чтобы отказаться от изменений. Для повторной загрузки страницы используйте действие обновления в меню виджета.

.. note::

   Внешний сайт может запрещать отображение во встроенном окне. В таком случае страница может не отображаться в виджете, даже если открывается в отдельной вкладке браузера.
