.. _type_parameters:

Описание параметров типа
=========================

Раздел содержит справочное описание основных параметров типа данных и правил их разрешения. Информация предназначена для разработчиков и администраторов, работающих с конфигурацией типов напрямую (через JSON, артефакты или API).

Для каждого параметра указано: тип значения, правила наследования от родительского типа и логика вычисления в случае, если значение не задано явно.

.. list-table::
      :widths: 5 10
      :class: tight-table

      * - **id: String**
        - Локальный идентификатор типа, уникальный в его рабочем пространстве. Не наследуется. В полной ссылке тип рабочего пространства имеет префикс пространства.
      * - **name: MLText**
        - Имя типа. Не наследуется. При пустом значении формируется из идентификатора типа.
      * - **description: MLText**
        - Описание типа. Не наследуется.
      * - **storageType: String**
        - | Тип хранилища: DEFAULT, ECOS_MODEL или ALFRESCO.
          | Для неабстрактного типа с DEFAULT и пустым sourceId под абстрактным родителем без источника используется политика хранилища родителя.
          | Для типа рабочего пространства принудительно используется ECOS_MODEL.
      * - **sourceId: String**
        - Идентификатор источника данных. Вычисляется по правилам:

          * Для типа рабочего пространства собственный sourceId очищается и вычисляется для ECOS_MODEL с учётом пространства.
          * При **storageType = ALFRESCO** устанавливается ``alfresco/``.
          * При **storageType = DEFAULT** пустое значение берётся из родителя с учётом правила выбора storageType выше.
          * При **storageType = ECOS_MODEL** пустое значение вычисляется на базе идентификатора типа; для абстрактных типов источник автоматически не создаётся.
          * Если непустое значение не содержит имени приложения, добавляется префикс ``emodel/``.

      * - **parentRef: EntityRef**
        - Ссылка на родительский тип. При пустом значении используется ``emodel/type@base``, кроме самого корневого типа base. Допускается глобальный родитель или родитель из того же рабочего пространства.
      * - **formRef: EntityRef**
        - Ссылка на форму. Наследуется если значение **пустое** И **inheritForm == true**.

          * Если ссылка указывает на **uiserv/form@DEFAULT_FORM**, то в formRef записывается **"uiserv/form@type$" + id типа**.

      * - **journalRef: EntityRef**
        - Ссылка на журнал. Не наследуется.

          * Если ссылка указывает на **uiserv/journal@DEFAULT_JOURNAL**, то в journalRef записывается **"uiserv/journal@type$" + id типа**.

      * - **defaultStatus: String**
        - Статус по умолчанию. Если не задан, то наследуется от родителя.
      * - **boardRef: EntityRef**
        - Ссылка на канбан доску. Не наследуется.
      * - **dashboardType: String**
        - Тип дашборда. Если не задан, то наследуется от родителя.
      * - **inheritForm: Boolean**
        - Флаг для включения и отключения наследования формы. Не наследуется.
      * - **inheritActions: Boolean**
        - Флаг для включения и отключения наследования действий. Не наследуется.
      * - **inheritNumTemplate: Boolean**
        - Флаг для включения и отключения наследования шаблона нумерации. Не наследуется.
      * - **dispNameTemplate: MLText**
        - Шаблон отображаемого имени. Если не задан, то наследуется от родителя.
      * - **numTemplateRef: EntityRef**
        - Шаблон нумерации. Если не задан и флаг inheritNumTemplate == true, то наследуются от родителя.
      * - **actions: List<EntityRef>**
        - Действия. При inheritActions == true родительские действия объединяются с собственными; повторяющиеся ссылки исключаются.
      * - **associations: List<AssocDef>**
        - Ассоциации объединяются по id. При совпадении id собственная конфигурация заменяет родительскую, но пустые attribute, target, name и незаданный child дозаполняются из родительской связи. Если родительского значения нет, часть настроек берётся из атрибута ASSOC. Подробнее — :ref:`datatypes_associations`.
      * - **defaultCreateVariant: Boolean?**
        - Нужно ли генерировать вариант создания по умолчанию. При null генерация включается, если собственный исходный список createVariants пуст. Для генерации требуется непустая ссылка на форму.
      * - **createVariants: List<CreateVariantDef>**
        - Варианты создания. Вычисляются по правилам:

          * При включённой генерации defaultCreateVariant и непустом formRef добавляется вариант с идентификатором **DEFAULT**.
          * При **inheritCreateVariants == true** добавляются варианты родителя. Собственные варианты с совпадающим id имеют приоритет.
          * Если **createVariantsForChildTypes == true**, то варианты создания текущего типа будут содержать варианты создания дочерних типов.
          * Пустые имя, форма, источник и действие после создания дозаполняются из разрешённого типа. Варианты без sourceId исключаются.
          * Для базовых типов base, user-base, case, data-list итоговый список вариантов пуст.

      * - **inheritCreateVariants: Boolean?**
        - Включает наследование вариантов создания. При null наследуется значение флага родителя; если оно также null, используется false.
      * - **createVariantsForChildTypes: Boolean**
        - Нужно ли добавлять в варианты создания варианты создания дочерних типов. Не наследуется.
      * - **configFormRef: EntityRef**
        - Форма для доп. конфига. Если не задана, то наследуется.
      * - **config: ObjectData**
        - Доп. конфиг. Не наследуется.
      * - **model: TypeModelDef**
        - Модель. Наследуется. Ниже подробнее.
      * - **↳ model.attributes**
        - Атрибуты типа. Наследуются от родителя и объединяются с атрибутами текущего типа. Если id совпадает, то происходит полное переопределение.
      * - **↳ model.systemAttributes**
        - Системные атрибуты типа. Наследуются от родителя и объединяются с системными атрибутами текущего типа. Если id совпадает, то происходит полное переопределение.
      * - **↳ model.roles**
        - Роли типа. Наследуются от родителя и объединяются с ролями текущего типа. Если id совпадает, то происходит полное переопределение.
      * - **↳ model.statuses**
        - Статусы типа. Наследуются от родителя и объединяются со статусами текущего типа. Если id совпадает, то происходит полное переопределение.
      * - **↳ model.stages**
        - Стадии типа. Если собственный список пуст, наследуется список родителя. Непустой собственный список заменяет родительский целиком.
      * - **docLib: DocLibDef**
        - Настройки библиотеки документов. Не наследуются.
      * - **contentConfig: TypeContentConfig**
        - Настройка работы с контентом. Наследуется. Ниже подробнее
      * - **↳ contentConfig.path**
        - Путь до атрибута с основным контентом документа. Если не задан, то наследуется от родителя.
      * - **↳ contentConfig.previewPath**
        - Путь до контента для предпросмотра. Если не задан, используется собственный явно заданный path; иначе — непустой previewPath родителя, затем разрешённый основной path.
      * - **↳ contentConfig.storageRef**
        - Ссылка на хранилище контента. Если не задана, то берется из родителя.
      * - **↳ contentConfig.storageConfig**
        - Конфигурация хранилища контента. Берется из родителя если storageRef не задан.
      * - **properties**
        - Доп. настройки типа. Не наследуются.
      * - **aspects**
        - Аспекты объединяются по ref. При совпадении ref и inheritConfig == true основой конфигурации служит конфигурация родительского аспекта; иначе используется defaultConfig аспекта. Собственные ключи config накладываются поверх выбранной основы.
      * - **queryPermsPolicy**
        - Политика поиска с проверкой прав. Наследуется от родителя если текущее значение DEFAULT
      * - **assignablePerms**
        - Назначаемые права. Объединяются с назначаемыми правами родительского типа.
      * - **localIdTemplate: String**
        - Шаблон локального идентификатора записи. Пустое значение наследуется от родителя; ``-`` отключает наследование шаблона.
      * - **postCreateActionRef: EntityRef**
        - Действие после создания записи. Пустое значение наследуется от родителя.
      * - **workspace: String**
        - Рабочее пространство типа. Пустое значение соответствует глобальному типу.
      * - **workspaceScope**
        - Видимость экземпляров в рабочих пространствах. У глобального типа DEFAULT наследуется от родителя. Для типа рабочего пространства применяется PRIVATE.
      * - **defaultWorkspace: String**
        - Рабочее пространство по умолчанию. У глобального типа пустое значение наследуется; у типа рабочего пространства используется пространство самого типа.
      * - **metaRecord: EntityRef**
        - Запись для получения метаданных. При пустом значении формируется как ``sourceId + '@'`` после разрешения источника.
      * - **system: Boolean**
        - Признак системного типа, используемый, в частности, для фильтрации журнала типов.
      * - **sourceRef: EntityRef**
        - Дополнительная ссылка на источник, сохраняемая в определении типа.

Для автоматически формируемых формы и журнала используется ID ``type$<id>``. У типа рабочего пространства в него включается префикс: ``type$<префикс_пространства>:<id>``.

Отображаемое имя сущности
--------------------------

Есть несколько сценариев для работы с отображаемым именем сущности.

    1. Если необходимо, чтобы имя сущности всегда формировалось по шаблону, то следует использовать поле ``dispNameTemplate`` в типе;
    2. Если необходимо, чтобы именем сущности можно было управлять, то следует в список атрибутов добавить атрибут с **id = 'name'**. Система автоматически будет использовать это поле для отображаемого имени (:ref:`скаляр<scalars>` **?disp** в Records API)

        a. Можно вывести поле name на форму и тогда пользователь сможет сам им управлять
        b. Можно поле **name** не выводить на форму, но позволить пользователю работать с ``_content`` атрибутом. В этом случае при загрузке нового контента автоматически будет изменяться поле name и => отображаемое имя.
