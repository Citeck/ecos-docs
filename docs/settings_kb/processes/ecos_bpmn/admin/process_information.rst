Информация о процессе
==========================================

.. contents::

.. image:: _static/adm_7.png
   :width: 600
   :align: center

Представлена обобщенная информация о процессе **(1)**:

    -	количество незавершённых экземпляров процесса по текущей версии, включая приостановленные;
    -	количество инцидентов по текущей версии;
    -	общее количество опубликованных версий;
    -	количество незавершённых экземпляров процесса по всем версиям, включая приостановленные.

Для просмотра данных экземпляров процесса необходимо право ``bpmn-process-instance-read``.

Действия

.. _actions_migration:

.. dropdown:: Миграция версий
   :color: secondary

   Вы можете перенести запущенные экземпляры процесса из текущей версии в другую версию, используя действие **Миграция версий**.

   Для генерации плана и выполнения миграции необходимо право ``bpmn-process-instance-migrate`` на исходную и целевую версии процесса.

      :width: 600
      :align: center

   .. image:: _static/migration_02.png
      :width: 700
      :align: center

   По нажатию на:

   .. list-table::
         :widths: 5 10
         :class: tight-table
         :align: center

         * -
             .. image:: _static/migration_02_1.png
                 :width: 30
                 :align: center

           - открывается карточка процесса с подробной информацией.

   На схеме исходной версии процесса отмечены счётчики текущих экземпляров элементов и инцидентов для выбранной версии процесса:

   .. image:: _static/migration_04_1.png
      :width: 600
      :align: center

   .. image:: _static/migration_04_2.png
      :width: 600

Инциденты
~~~~~~~~~~~~~~~~~~~~~

**Список инцидентов** в запущенных экземплярах процесса для выбранной версии процесса:

.. image:: _static/adm_17.png
   :width: 600
   :align: center

Фильтрация инцидентов по сообщению работает только для тех инцидентов, которые произошли в текущей области видимости. Например, если из процесса А через callActivity вызывается процесс B и инцидент произошёл внутри процесса B, связанный инцидент будет показан в списке процесса А, но фильтрация по сообщению его корневой причины работать не будет.

Для добавления комментария к инциденту и изменения количества попыток выполнения задания необходимо право ``bpmn-process-instance-edit``.

По клику на **Экземпляр процесса** открывается подробная информация о нем. См. :ref:`подробно Экземпляр процесса <process_instance>`.

По клику на **Элемент**, **Отказавший элемент** — элемент будет подсвечен на схеме:
