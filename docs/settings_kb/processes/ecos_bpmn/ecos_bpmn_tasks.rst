.. _tasks_options:

Работа с задачами бизнес-процесса
==================================================================

.. contents::

При работе с бизнес-процессом на пользователей назначаются задачи. Ниже описаны варианты действий с задачами.

Права
------

Права на операции имеют:

    - администраторы Citeck;

    - пользователи, являющиеся реципиентами задачи.

Дополнительно права на переназначение (изменить исполнителя) задачи имеют пользователи, входящие в группу ``GROUP_WORKFLOW_TASKS_REASSIGN_ALLOWED``.

Действия с задачей
-------------------

.. grid:: 1
   :gutter: 2

   .. grid-item-card:: Я выполню это
      :link: task_execute
      :link-type: ref

      Заберите задачу с пула реципиентов (группы или нескольких пользователей) и назначьте на себя.

   .. grid-item-card:: Назначить / Изменить исполнителя
      :link: task_reassign
      :link-type: ref

      Заберите задачу из пула реципиентов и назначьте на выбранного пользователя.

   .. grid-item-card:: Вернуть на группу
      :link: task_return_to_group
      :link-type: ref

      Верните задачу, ранее забранную на конкретного пользователя, обратно на изначальный пул реципиентов.

   .. grid-item-card:: Просмотр схемы бизнес-процесса
      :link: task_view_scheme
      :link-type: ref

      Откройте схему бизнес-процесса с выделенной текущей задачей.

.. _task_execute:

Я выполню это
~~~~~~~~~~~~~

.. image:: _static/task_1.png
   :width: 700
   :align: center

Действие доступно, если задача назначена на пул реципиентов — группу или нескольких пользователей.
При выполнении действия задача забирается с реципиентов и назначается на текущего пользователя.

.. _task_reassign:

Назначить / Изменить исполнителя
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. image:: _static/task_2.png
   :width: 700
   :align: center

Действие забирает задачу из пула реципиентов и назначает на выбранного пользователя.

.. note::

    Если задача переназначается на пользователя, у которого нет прав на чтение документа, по которому идет бизнес-процесс, то переназначающий пользователь делегирует права на чтение к документу.
    Делегация прав сохраняется после завершения задачи и доступна пока у делегата есть соответствующие права.

.. _task_return_to_group:

Вернуть на группу
~~~~~~~~~~~~~~~~~

.. image:: _static/task_3.png
   :width: 700
   :align: center

Действие возвращает задачу на изначальный пул реципиентов.
Доступно, если задача была ранее забрана с пула реципиентов на конкретного пользователя.
