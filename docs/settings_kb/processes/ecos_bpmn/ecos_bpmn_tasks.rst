.. _tasks_options:

Работа с задачами бизнес-процесса
==================================================================

.. contents::

При работе с бизнес-процессом на пользователей назначаются задачи. Ниже описаны варианты действий с задачами.

Права
------

Права на получение задачи, назначение исполнителя и возврат задачи в пул реципиентов имеют:

    - администраторы Citeck;

    - назначенный исполнитель задачи;

    - пользователи, являющиеся реципиентами задачи, в том числе участники групп реципиентов;

    - заместители исполнителя или реципиентов при действующем замещении для типа документа, по которому запущен процесс.

Дополнительно права на переназначение (изменить исполнителя) задачи имеют пользователи, входящие в группу ``GROUP_WORKFLOW_TASKS_REASSIGN_ALLOWED``.

Доступность действия также зависит от состояния задачи: наличия исполнителя и реципиентов.

.. _task_execute:

Я выполню это
~~~~~~~~~~~~~

.. image:: _static/task_1.png
   :width: 700
   :align: center

Действие доступно, если задача не назначена конкретному исполнителю и у неё есть реципиенты — пользователи или группы.
При выполнении действия задача забирается из пула реципиентов и назначается на текущего пользователя.

.. _task_reassign:

Назначить / Изменить исполнителя
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. image:: _static/task_2.png
   :width: 700
   :align: center

Если задача находится в пуле реципиентов, действие **Назначить** назначает её выбранному пользователю.
Если у задачи уже есть исполнитель, действие **Изменить исполнителя** заменяет его выбранным пользователем. Для смены исполнителя наличие пула реципиентов не требуется.

.. note::

    При назначении выбранному пользователю или смене исполнителя, если у нового исполнителя нет права на чтение документа, по которому идёт бизнес-процесс, ему делегируется право чтения от пользователя, выполняющего назначение.

.. _task_return_to_group:

Вернуть на группу
~~~~~~~~~~~~~~~~~

.. image:: _static/task_3.png
   :width: 700
   :align: center

Действие снимает назначенного исполнителя и возвращает задачу в сохранённый пул реципиентов.
Доступно, если у задачи есть исполнитель и сохранённые реципиенты для возврата.

Пул сохраняется при получении или назначении задачи из пула реципиентов. При синхронизации ролевых реципиентов его состав может обновляться, поэтому он не всегда совпадает с составом на момент создания задачи.
