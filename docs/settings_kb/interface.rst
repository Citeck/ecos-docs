.. _interface:

Интерфейс
=========

Раздел охватывает настройку всех ключевых элементов интерфейса Citeck:

.. grid:: 1
   :gutter: 3

   .. grid-item-card:: Формы
      :link: forms
      :link-type: ref

      Графическое представление объектов в виде набора полей для ввода и редактирования данных: конструктор форм, компоненты, локализация, черновики и связь форм с задачами процесса.

   .. grid-item-card:: Журналы
      :link: journals
      :link-type: ref

      Табличное представление объектов с фильтрацией, группировкой и действиями над записями: создание журналов, режимы отображения (таблица, канбан, плитки, библиотека документов), групповые действия и вычисляемые атрибуты.

   .. grid-item-card:: Меню
      :link: menu
      :link-type: ref

      Навигационная панель Citeck с поддержкой гибкой настройки под группы пользователей: структура конфигурации, типы элементов, приоритеты групп и решение типичных проблем.

   .. grid-item-card:: Дашборды
      :link: dashboard
      :link-type: ref

      Настраиваемые домашние страницы пользователя или страницы кейса с поддержкой размещения и конфигурации виджетов.

   .. grid-item-card:: Виджеты
      :link: widgets
      :link-type: ref

      Блоки отображения информации на дашбордах: документы, задачи, процессы, пользователи и другие данные системы.

   .. grid-item-card:: Темы интерфейса
      :link: interface_themes
      :link-type: ref

      Визуальная кастомизация Citeck: загрузка и применение пользовательских логотипов, favicon и CSS-стилей в виде zip-архива.
