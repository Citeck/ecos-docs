Обновление Citeck
-------------------

1. Остановите namespace и дождитесь статуса **Остановлен**. Создайте :ref:`снэпшот данных <launcher_dump>` и дождитесь завершения экспорта. Сохраните сведения о текущем бандле. Если планируется перенос в другое окружение, подготовьте снэпшот с секретами, как описано в разделе :ref:`о переносе снэпшотов <launcher_snapshot_transfer>`.

2. Перейдите в **режим редактирования** namespace:

   .. image:: _static/update_01.png
       :width: 600
       :align: center

3. Выберите **бандл** нового релиза и нажмите **Сохранить**:

   .. image:: _static/update_02.png
       :width: 600
       :align: center

4. Нажмите **Обновить и запустить**. Действие сразу запускает обновление; отдельное подтверждение запуска не требуется. Для закрытых образов при необходимости выберите или добавьте учётные данные реестра:

   .. image:: _static/update_03.png
       :width: 600
       :align: center

5. Начнётся скачивание и разворачивание образов:

   .. image:: _static/update_05.png
       :width: 600
       :align: center

6. Дождитесь статуса **Работает** всех необходимых микросервисов и приложений, затем нажмите **Открыть в браузере**.

.. note::

    Обновление сохраняет данные томов, но новый релиз может потребовать миграции данных или инфраструктурных зависимостей. Ознакомьтесь с требованиями релиза. Возврат к старому бандлу сам по себе не отменяет выполненные миграции; для восстановления используйте подготовленный снэпшот и совместимые версии зависимостей. Подробнее — `миграция PostgreSQL <https://github.com/Citeck/citeck-launcher/blob/master/docs/postgres-major-upgrade.md>`_.
