Обновление namespace до нового релиза
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Если в репозитории бандлов появилась версия новее текущей, на шестерёнке настроек namespace (рядом с его названием) появляется точка: **зелёная** — новый бандл можно выбрать сразу, **жёлтая** — он требует более новой версии лаунчера, и сначала нужно :ref:`обновить лаунчер <launcher_self_update>`. Наведите курсор на шестерёнку, чтобы узнать версию.

1. Создайте :ref:`снэпшот данных <launcher_dump>`, чтобы при необходимости можно было восстановить исходное состояние.

2. Перейдите в **режим редактирования** namespace:

   .. image:: _static/update_01.png
       :width: 600
       :align: center

3. Выберите **бандл** нового релиза и нажмите **Сохранить**:

   .. image:: _static/update_02.png
       :width: 600
       :align: center

   Если нужной версии нет в списке, нажмите кнопку обновления списка бандлов рядом с полем — лаунчер загрузит изменения репозитория.

   .. note::

       Бандл может требовать минимальную версию лаунчера. Если установленный лаунчер старее, сохранение будет отклонено с указанием версии, до которой нужно обновиться. Вариант **LATEST** всегда выбирает самый новый бандл, который текущий лаунчер способен запустить.

4. Нажмите кнопку запуска:

   .. image:: _static/update_03.png
       :width: 600
       :align: center

5. Нажмите **Обновить и запустить**:

   .. image:: _static/update_04.png
       :width: 600
       :align: center

6. Начнётся скачивание и разворачивание образов. Пересоздаются только те сервисы, у которых изменились образ или конфигурация:

   .. image:: _static/update_05.png
       :width: 600
       :align: center

7. Дождитесь статуса **Работает** микросервисов и приложений, затем нажмите **Открыть в браузере**.

.. note::

    Данные не удаляются автоматически при обновлении — для их удаления требуется явное действие.

**Сторонние компоненты.** Новый бандл может предлагать новую версию PostgreSQL, RabbitMQ, ZooKeeper и других зависимостей, несовместимую с уже существующими данными. Такая версия не применяется автоматически: namespace продолжает работать на прежней, а лаунчер показывает сообщение **Доступно обновление зависимости** и предлагает выполнить миграцию, когда вы будете готовы. См. :ref:`Обновление зависимостей <launcher_dependencies>`.

**Новые приложения.** Если новый бандл добавляет приложение, которое шаблон рабочего пространства относит к необязательным, оно появится в статусе **Остановлен** и не запустится само. См. :ref:`Какие приложения запускаются <launcher_detached_apps>`.

.. _launcher_self_update:

Автообновление лаунчера
~~~~~~~~~~~~~~~~~~~~~~~

Лаунчер сам проверяет наличие новых версий (при запуске и затем каждые 4 часа) и обновляется на Windows, Linux и macOS. Скачанное обновление проверяется по цифровой подписи перед установкой.

Когда доступна новая версия, на значке загрузки в правом верхнем углу появляется зелёная точка. Нажмите на значок — откроется окно со списком изменений новой версии:

- **Обновить и перезапустить** — скачать и установить обновление;
- **Проверить сейчас** — проверить наличие обновлений вручную;
- **Отмена** — закрыть окно (доступна всегда, в том числе во время установки).

При обновлении перезапускается только служебная часть лаунчера: запущенные контейнеры namespace продолжают работать, а окно лаунчера обновляется само, как только запустится новая версия.

Если новая версия не смогла запуститься, лаунчер автоматически откатывается на прежнюю. На значке загрузки появляется красная точка, а в окне обновления — сообщение **Обновление до <версия> не установилось** и кнопка **Попробовать снова**. Повторно установить неудачное обновление лаунчер сам не пытается — только по вашей команде.

Если текущая версия не может установить обновление автоматически, окно обновления сообщит об этом и предложит открыть `страницу релизов <https://github.com/Citeck/citeck-launcher/releases>`_, чтобы скачать дистрибутив вручную.

.. note::

    После обновления лаунчера некоторые контейнеры могут быть однократно пересозданы при следующем запуске namespace — например, если новая версия меняет их параметры. Данные при этом сохраняются.
