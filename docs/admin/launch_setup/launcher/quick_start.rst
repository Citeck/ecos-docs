.. _quick_start:

Быстрый запуск Citeck
=====================

1. Убедитесь, что установлены необходимые компоненты:

   - Установлен `Docker <https://docs.docker.com/get-docker/>`_
   - Не менее **16 ГБ** ОЗУ

2. Запустите **Docker**.

   .. note::

       По умолчанию Windows выделяет 50 % общей памяти для WSL 2. Для увеличения объёма воспользуйтесь `инструкцией <https://learn.microsoft.com/ru-ru/windows/wsl/wsl-config#configuration-settings-for-wslconfig>`_.

3. Скачайте и установите актуальный дистрибутив **citeck-launcher** для вашей ОС со `страницы релизов <https://github.com/Citeck/citeck-launcher/releases>`_:

   - **.msi** — для Windows
   - **.deb** — для Linux-подобных ОС
   - **.dmg** — для macOS

   .. note::

       При установке на Windows, если **SmartScreen** предотвратил запуск приложения, нажмите **«Подробнее»**, а затем **«Выполнить в любом случае»**:

       .. image:: _static/01.png
           :width: 300
           :align: center

   .. note::

       На macOS при первом запуске система может предупредить, что приложение получено от неустановленного разработчика. Откройте его один раз через контекстное меню: правый клик по приложению → **«Открыть»**.

   Устанавливать новые версии вручную в дальнейшем не требуется — лаунчер обновляется сам, см. :ref:`Автообновление лаунчера <launcher_self_update>`.

4. Запустите **Citeck Launcher**:

   .. image:: _static/01_1.png
       :width: 400
       :align: center

5. Выберите вариант запуска **Citeck**:

   - с предзаполненными :ref:`демонстрационными данными <ecos_modules>` — нажмите **Quick Start With Demo Data**:

     .. image:: _static/fast_start.png
         :width: 600
         :align: center

   - без демонстрационных данных — нажмите **Quick Start Without Demo Data**.

   Названия и состав вариантов быстрого старта задаются в конфигурации :ref:`рабочего пространства <launcher_workspace>`; выше приведены варианты рабочего пространства по умолчанию.

   Ход запуска отображается по этапам: **Репозиторий и бандл**, **Загрузка образов**, **Старт инфраструктуры**, **Старт приложений**, **Готово**. Окно прогресса можно скрыть кнопкой **Скрыть** или перейти к панели управления кнопкой **Открыть панель** — запуск при этом продолжается.

   Дождитесь загрузки и проверки данных:

   .. image:: _static/data_load.png
       :width: 600
       :align: center

.. dropdown:: Enterprise: ввод учётных данных Harbor
   :color: secondary

   При установке Enterprise версии для скачивания закрытых образов необходимы учётные данные реестра. Лаунчер откроет окно **Вход в <реестр>**: выберите сохранённые учётные данные или добавьте новые (**Добавить новый…**) и нажмите **Сохранить и повторить**. Если в лаунчере ещё нет ни одного секрета, он попросит создать :ref:`мастер-пароль <launcher_secrets>`, которым шифруются учётные данные.

   Если окно было закрыто, над списком приложений останется сообщение **Нужны учётные данные реестра для: …** с кнопкой **Указать креды**. Сохранённую привязку реестра к учётным данным можно изменить позже на странице **Настройки** → **Учётные данные реестров**.

6. Скачивание и разворачивание образов начнётся автоматически:

   .. image:: _static/pulling.png
       :width: 700
       :align: center

7. Дождитесь статуса **Работает** микросервисов и приложений, затем нажмите **Открыть в браузере**:

   .. image:: _static/open.png
       :width: 700
       :align: center

   .. note::

       Часть необязательных приложений (например, **observer** и его база **observer-postgres**) создаётся в статусе **Остановлен** и не запускается автоматически — так настроен шаблон рабочего пространства. Чтобы включить такое приложение, нажмите кнопку запуска в его строке; после этого оно будет запускаться вместе с namespace. Подробнее — в разделе :ref:`Какие приложения запускаются <launcher_detached_apps>`.

8. Войдите в систему:

   .. grid:: 2
       :gutter: 2

       .. grid-item::

          Используйте учётные данные **admin / admin**:

          .. image:: _static/page_01.png
              :width: 350
              :align: center

       .. grid-item::

          При первом развёртывании без демонстрационных данных Keycloak попросит сменить пароль:

          .. image:: _static/page_02.png
              :width: 350
              :align: center

9. По адресу http://localhost/ откроется страница :ref:`персонального рабочего пространства <ws_personal>`. По умолчанию Citeck доступен только с этого компьютера — порты публикуются на адресе 127.0.0.1 (см. :ref:`Порты и доступ из сети <launcher_ports>`):

   .. image:: _static/page_04.png
       :width: 700
       :align: center

   .. note::

       В первые 5 минут после запуска могут появляться ошибки — это нормально, развёртывание продолжается:

       .. image:: _static/page_05.png
           :width: 300
           :align: center

|

.. note::

    Для экономии ресурсов можно остановить микросервис **onlyoffice** и изменить аутентификацию с Keycloak на **BASIC**. Остановленное вручную приложение остаётся остановленным и после перезапуска лаунчера — до тех пор, пока вы не запустите его снова.
