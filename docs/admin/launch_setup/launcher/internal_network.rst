Запуск в закрытом контуре
============================

Для развёртывания в среде без доступа к интернет необходимо сначала загрузить Docker-образы на компьютере с интернетом, экспортировать их в файлы, перенести на носителе и импортировать в закрытом контуре.

.. important::

    Архитектура процессора должна совпадать на обоих компьютерах (на том, где загружаете образы, и на том, где развёртываете в закрытом контуре).

**1. На компьютере с интернетом — загрузить образы**

Запустите систему через Launcher и дождитесь, пока образы загрузятся в Docker.

**2. На компьютере с интернетом — сохранить образы в файлы**

Сохраните нужные образы в tar-архив:

.. code-block:: shell

    # Сохранить один образ
    docker save some-image:2026.1 -o citeck-some-image-2026.1.tar

    # Сохранить несколько образов в один архив
    docker save \
        image-a:2026.1 \
        image-b:2026.1 \
        -o citeck-2026.1-bundle.tar

**3. Перенести файлы на носителе** (USB-накопитель, сетевой диск или другой носитель) в закрытый контур.

**4. На компьютере без интернета — загрузить образы**

.. code-block:: shell

    # Загрузить из tar-архива
    docker load -i citeck-some-image-2026.1.tar
