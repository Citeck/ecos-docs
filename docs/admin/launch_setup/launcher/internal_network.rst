Запуск в закрытом контуре
============================

Для развёртывания в среде без доступа к интернет необходимо сначала загрузить Docker-образы на хосте с интернетом, экспортировать их в файлы, перенести на носителе и импортировать в закрытом контуре.

.. important::

    Архитектура процессора должна совпадать на обоих хостах (на том, где загружаете образы, и на том, где развёртываете в закрытом контуре).

**1. На хосте с интернетом — загрузить образы**

Запустите систему через Launcher и дождитесь, пока образы загрузятся в Docker.

**2. На хосте с интернетом — сохранить образы в файлы**

Сохраните нужные образы в tar-архив:

.. code-block:: shell

    # Сохранить один образ
    docker save some-image:X.Y -o citeck-some-image-X.Y.tar

    # Сохранить несколько образов в один архив
    docker save \
        image-a:X.Y \
        image-b:X.Y \
        -o citeck-X.Y-bundle.tar

**3. Перенести файлы на носителе** (USB-накопитель, сетевой диск или другой носитель) в закрытый контур.

**4. На хосте без интернета — загрузить образы**

.. code-block:: shell

    # Загрузить из tar-архива
    docker load -i citeck-some-image-X.Y.tar
