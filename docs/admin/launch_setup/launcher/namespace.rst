Создание нового пространства имён
-----------------------------------

Для запуска другого комплекта поставки создайте новый namespace — нажмите **Создать новый namespace**:

.. image:: _static/new_namespace.png
    :width: 600
    :align: center

Укажите параметры нового пространства имён:

.. list-table::
   :header-rows: 1
   :class: tight-table

   * - Параметр
     - Описание
   * - **Имя**
     - Имя namespace.
   * - **Репозиторий бандла**
     - Список определяется workspace. Например, **enterprise** или **community** — стабильные релизы, **enterprise-rc** или **community-rc** — релиз-кандидаты. Для рабочих контуров RC использовать не рекомендуется.
   * - **Бандл**
     - Версия поставки.
   * - **Снэпшот**
     - Снэпшот данных (при необходимости). Workspace может задавать минимальную совместимую версию бандла; недоступные варианты сопровождаются причиной ограничения.
   * - **Тип аутентификации**
     - **KEYCLOAK** — вход через Keycloak; **BASIC** — базовая аутентификация. Для BASIC укажите непустой список пользователей через запятую, например ``admin, user1``.
   * - **Хранилище контента**
     - Хранение в БД или S3. Доступность S3 и используемый провайдер зависят от бандла. При редактировании переход с БД на S3 односторонний: обратное переключение в этом диалоге не поддерживается.
   * - **Включить HTTPS (самоподписанный)**
     - В диалоге неймспейса отдаёт прокси по HTTPS с автоматически сгенерированным сертификатом. Порт следует за схемой автоматически — 443 для HTTPS, 80 для HTTP — поэтому включение и выключение HTTPS просто работает. При первом входе браузер покажет предупреждение о самоподписанном сертификате.

.. image:: _static/new_namespace_1.png
    :width: 400
    :align: center

В зависимости от выбранного бандла в дополнительных настройках также доступны переключатель MongoDB и экспериментальные функции. Состав параметров и их доступность могут различаться между поставками.

Нажмите **Создать**.

Если выбран снэпшот данных, дождитесь его загрузки и проверки. Для запуска нажмите **Обновить и запустить**:

.. image:: _static/new_namespace_2.png
    :width: 700
    :align: center

Для загрузки образов Enterprise версии необходимы учетные данные. Выберите существующие или добавьте новые:

.. image:: _static/harbor_1.png
    :width: 400
    :align: center

Введите мастер-пароль или установите его, если он ещё не задан:

.. image:: _static/new_namespace_2_1.png
    :width: 400
    :align: center
