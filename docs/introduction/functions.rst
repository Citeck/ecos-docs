.. _cross_module_functions:

Описание отдельных функциональностей
=====================================

В разделе описаны кросс-модульные функциональности платформы Citeck — инструменты, доступные в различных модулях системы независимо от конкретного бизнес-процесса или типа записи.

.. rubric:: Работа с записями и журналами

Инструменты для просмотра, структурирования и управления записями в журналах и карточках.

.. grid:: 1
   :gutter: 2

   .. grid-item-card:: Действия в карточках
      :link: actions
      :link-type: ref

      Набор встроенных действий для управления записью: редактирование свойств, печать, загрузка новой версии, создание поручений.

   .. grid-item-card:: Предпросмотр карточки
      :link: preview
      :link-type: ref

      Встроенный режим просмотра данных записи прямо из журнала, без открытия полной карточки.

   .. grid-item-card:: Представление «Иерархия»
      :link: hierarchical-view
      :link-type: ref

      Отображение записей журнала в виде дерева с возможностью добавлять, редактировать и перемещать элементы перетаскиванием.

   .. grid-item-card:: Дерево категорий
      :link: category_tree
      :link-type: ref

      Инструмент для иерархической организации записей журнала по произвольным категориям.

   .. grid-item-card:: Клиент 360
      :link: client_360
      :link-type: ref

      Подход к работе с контрагентами: вся информация о клиенте собрана в едином месте — история взаимодействий, документы, задачи и связанные записи.

.. rubric:: Работа с документами и файлами

Инструменты для создания, редактирования, генерации и подписания документов.

.. grid:: 1
   :gutter: 2

   .. grid-item-card:: Редактирование в OnlyOffice
      :link: edit_only_office
      :link-type: ref

      Открытие и редактирование файлов форматов MS Office и OpenDocument прямо в браузере без сторонних приложений.

   .. grid-item-card:: WYSIWYG-редактор
      :link: wysiwyg_editor
      :link-type: ref

      Визуальный редактор для создания форматированного контента: текст, таблицы, изображения и формулы.

   .. grid-item-card:: Шаблоны документов
      :link: doc_templates
      :link-type: ref

      Автоматическая генерация файлов (docx и др.) на основе заранее подготовленных шаблонов и данных из карточек записей.

   .. grid-item-card:: Сравнение версий
      :link: version_comparison
      :link-type: ref

      Наглядное отображение различий между двумя версиями документа: добавленные, изменённые и удалённые фрагменты подсвечиваются в интерфейсе.

   .. grid-item-card:: Штрихкод в PDF
      :link: barcode_pdf
      :link-type: ref

      Автоматическое формирование PDF-документа со встроенным штрихкодом для идентификации и отслеживания документов в бизнес-процессах.

   .. grid-item-card:: Электронная подпись (ЭЦП)
      :link: esign
      :link-type: ref

      Подписание документов с использованием усиленной квалифицированной электронной подписи (УКЭП), обеспечивающей юридическую значимость.

.. rubric:: Организация работы

Инструменты для распределения задач и управления рабочим временем.

.. grid:: 1
   :gutter: 2

   .. grid-item-card:: Делегирование
      :link: delegation
      :link-type: ref

      Механизм передачи задач и полномочий другим сотрудникам — на период отсутствия или на постоянной основе.

   .. grid-item-card:: Рабочее расписание и производственный календарь
      :link: business-schedule
      :link-type: ref

      Инструменты для управления рабочим временем: настройка графиков, праздников и нерабочих дней, используемых в бизнес-процессах.

Инструменты для массового наполнения системы данными.

.. grid:: 1
