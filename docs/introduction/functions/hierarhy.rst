Представление «Иерархия»
===========================

**Иерархия** - способ организации данных в виде дерева, где каждый элемент (узел) может иметь несколько дочерних элементов. 

Для выбора представления **Иерархия** нажмите **(1)**.

 .. image:: _static/hierarchical/Hierarchical_01.png
       :width: 700
       :align: center

В представлении доступны следующие действия:

 - **(2)** — добавление элемента 1-го уровня
 - **(3)** — добавление элемента уровнем ниже
 - **(4)** — редактирование элемента
 - **(5)** — удаление элемента
 - **(6)** — свернуть / развернуть структуру иерархии

Перемещение элементов осуществляется перетаскиванием.

Как добавить представление «Иерархия» в тип данных и форму, смотрите :ref:`пример <sample_select_hierarchical_component>`.
