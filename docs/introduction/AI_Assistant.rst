.. _AI_assistant:

Citeck AI Ассистент
==========================

.. contents::
    :depth: 6

Встроенный AI-ассистент платформы Citeck автоматизирует бизнес-процессы, упрощает работу с документами и помогает управлять данными.

.. note::

    Ассистент доступен в Enterprise версии Citeck при соблюдении следующих условий:

        1. **Лицензия:** наличие флага ``ai`` в лицензии
        2. **Права пользователя:** пользователь должен быть в группе ``GROUP_ai-feature-allowed`` или иметь права администратора/системы
        3. **Микросервис:** подключен и настроен микросервис ``ecos-ai`` (:ref:`см. конфигурацию<AI_assistant_config>`)


Интерфейс пользователя
-----------------------

.. image:: _static/AI_Assistant/main.png
    :width: 800
    :align: center
    :alt: Интерфейс AI-ассистента

- **1** - режимы работы ассистента:

    - **Операционный режим** — включён по умолчанию. Работа с данными: поиск и создание записей, задачи, документы, аналитика.
    - **Конфигурация платформы** — настройка приложения: типы данных, формы, процессы и скрипты. Изменения выполняются пошагово и вступают в силу только после подтверждения пользователем.

- **2** - выбор специализированного :ref:`агента <AI_context_and_agent>`.
- **3** - выбранное рабочее пространство.
- **4** - ввод и отправка запроса, добавление файла, очистка контекста.


.. _AI_context_and_agent:

Готовые агенты
~~~~~~~~~~~~~~~~~~~~~

Через меню выбора агента **(2)** доступны специализированные AI-агенты. 

Агент — предустановленная роль ассистента со своим набором инструментов и системным промптом, заточенная под конкретный круг задач, например работу с документами или конфигурацию платформы.


.. image:: _static/AI_Assistant/agents.png
    :width: 400
    :align: center
    :alt: Интерфейс AI-ассистента


**Операционные:**

    -	**Помощник по задачам и документам** - поиск и выполнение задач, поиск документов по метаданным и содержимому, анализ и изменение метаданных документов. Обслуживает чат без явно выбранного агента.
    -	**Агент конфигурации платформы** - создание, изменение и развёртывание артефактов платформы (типов данных, форм и BPMN-процессов).
    -	**Помощник по изображениям** - генерация и редактирование изображений по текстовому описанию, анализ загруженных изображений.
    -	**Помощник по возможностям платформы** - отвечает на вопросы о возможностях платформы по ее документации, указывая ссылки на конкретные разделы.

**Конфигурация платформы:**

    -	**Аудитор конфигурации** - аудит конфигурации бизнес-приложения: безопасность (права, роли, чувствительные данные) и качество (модель данных, статусы, процессы, формы). Только в режиме чтения.
    -	**Оператор публикации конфигурации** - проверка артефакта перед публикацией, оценка влияния на зависимые артефакты и вынесение решения о публикации. Публикует только после подтверждения человеком.

Конкретные примеры и подробное описание возможностей см. в разделе :ref:`Примеры и подробное описание возможностей <AI_examples>`.

Полный состав инструментов и системные промпты агентов см. в разделе :ref:`Преднастроенные агенты <preconfigured-agents>`.


Горячие клавиши
~~~~~~~~~~~~~~~~~~

    -	``Cmd+I`` (Mac) / ``Alt+I`` (Windows/Linux) - открыть/закрыть AI-ассистента
    -	``Enter`` - отправить сообщение
    -	``Shift+Enter`` - новая строка
    -	``Escape`` - закрыть чат

Контекстная работа
-------------------

Чем более детально вы сформируете свой вопрос / требования к генерации, тем более точный ответ вы получите.

Добавление контекста
~~~~~~~~~~~~~~~~~~~~

Используйте символ **`@`** для добавления дополнительного контекста к запросам:

    -	`@запись` - добавить данные текущей открытой записи
    -	`@имя_документа` - найти и добавить конкретный документ по названию или номеру.

.. note::

    Поиск по `@` выполняется только среди записей того же типа данных, что и текущий открытый документ. Например, если открыт Договор — можно искать другие договоры через `@договор №230`.

Попробуйте создать :ref:`процесс заявки на закупку оборудования<sample_request_ai>` с помощью интеллектуального помощника.

Умное подключение контекста записей
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- **Поиск артефакта по имени:** при работе с конфигурацией платформы AI-ассистент находит артефакт (тип данных, форму, процесс, журнал, дашборд, приложение) по названию прямо из запроса пользователя, без явного @-упоминания. Поиск идёт в рабочем пространстве диалога и в глобальной области, под правами пользователя
- **Уточнение при неоднозначности:** если под название подходит несколько артефактов, ассистент перечисляет найденные варианты и уточняет в диалоге, какой именно имелся в виду

Примеры и подробное описание возможностей
--------------------------------------------

Генерация и автоматизация
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Возможности AI-ассистента по автоматической генерации артефактов платформы Citeck: от целых бизнес-приложений до отдельных типов данных, форм, BPMN-процессов и скриптов. Ассистент также умеет самостоятельно писать техническую документацию по созданным приложениям и искать ответы в документации Citeck.

Генерация бизнес-приложений
""""""""""""""""""""""""""""""""

.. _AI_app_generation:

Создание полноценных бизнес-приложений из текстового описания с автоматической генерацией всех необходимых компонентов.

    - **Генерация приложений** - создание полноценных бизнес-приложений из текстового описания
    - **Типы данных** - автоматическое создание типов данных с атрибутами, ролями и статусами
    - **BPMN-процессы** - генерация бизнес-процессов для автоматизации логики
    - **Связанные сущности** - поддержка нескольких связанных типов данных в одном приложении
    - **Уточняющие вопросы** - при недостаточно детальном запросе ассистент задаёт вопросы, при необходимости в несколько раундов. На каждом раунде доступны кнопки **Пропустить** (генерировать с разумными допущениями) и **Отмена**; вместо ответов на вопросы можно приложить файл спецификации
    - **Утверждение плана** - перед генерацией показывается план со структурой будущего приложения: атрибуты, статусы и роли типов данных, ключевые поля форм и шаги процессов. Генерация начинается только после подтверждения; свободным текстом можно попросить изменить план или задать вопрос о нём
    - **Пошаговый индикатор** - ход генерации отображается стадиями: анализ требований, уточняющие вопросы, типы данных, формы, процессы, развертывание
    - **Развертывание** - создание артефактов в системе; при отмене или ошибке индикатор явно сообщает о завершении, диалог продолжается штатно

.. dropdown:: Процесс работы
   :color: secondary

   1. Опишите бизнес-требования на естественном языке
   2. AI проанализирует запрос и при необходимости задаст уточняющие вопросы (можно пропустить или приложить спецификацию)
   3. Система предложит план приложения со структурой типов данных, форм и процессов
   4. Подтвердите план, запросите изменения или задайте вопрос о нём
   5. AI создаст и развернет все компоненты, показывая ход работы пошаговым индикатором

""""""""""""""""""

Помощник BPMN
""""""""""""""""""

.. _AI_bpmn_generation:

Специализированный помощник для работы с бизнес-процессами в BPMN-редакторе.

    -	**Генерация BPMN** процессов из текстового описания
    -	**Редактирование BPMN** с помощью AI
    -	**Контекстная помощь** на основе текущего процесса и типа данных
    -   **AI Task с прямыми вызовами LLM** - AI-задачи внутри BPMN-процессов могут делать прямые вызовы к LLM через BpmnAiService
    -   **Режим вопрос-ответ** -  BPMN-ассистент поддерживает свободные вопросы пользователя

**Запросы:**

    * *Создай процесс согласования отпуска у руководителя на основе типа данных*

При генерации BPMN-процесса AI-ассистент учитывает выбранный тип данных в редакторе BPMN для указания ролей, статусов и смысловой нагрузки элементов процесса.

Ассистент написания скриптов
""""""""""""""""""""""""""""""""""""

.. _AI_script_assistant:

Специализированный помощник для создания и редактирования скриптов в процессах, вычисляемых полях, условиях, UI-действиях и журналах Citeck.

.. dropdown:: Как использовать
   :color: secondary

   1. Откройте любой редактор скриптов (BPMN Script Task, вычисляемый атрибут и др.)
   2. Нажмите на кнопку AI-ассистента в правом нижнем углу редактора
   3. В появившемся поле ввода опишите, что должен делать скрипт, или выберите быстрое действие
   4. Ассистент сгенерирует код с подробным объяснением логики

**Поддерживаемые контексты:**

    - **BPMN Script Task** — скрипты внутри бизнес-процессов
    - **Gateway / Sequence Flow Condition** — условия маршрутизации процессов
    - **Computed Attribute** — вычисляемые атрибуты типов данных
    - **Computed Role** — динамическое определение участников ролей
    - **UI Action Script** — клиентские скрипты действий
    - **Journal Formatter** — форматирование ячеек журналов
    - **Консоль разработчика** — скрипты в консоли администратора

**Возможности:**

    - **Генерация скриптов** на основе текстового описания
    - **Редактирование** и **улучшение** существующих скриптов
    - **Быстрые действия:** объяснение кода, исправление ошибок, оптимизация
    - **Генерация** вычисляемых атрибутов и форматтеров журналов
    - **Валидация API** - проверка использования только доступных API для контекста
    - **Контекстно-зависимая генерация** - учёт метаданных типа данных, атрибутов, ролей и статусов

Задачи и работа с записями
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Работа с записями
""""""""""""""""""

.. _AI_records_work:

Ассистент может искать, показывать и изменять любые записи в системе Citeck — карточки клиентов, документы, договоры, заказы, обращения и другие объекты.

    -	**Поиск записей** — по названию, статусу, дате или другим признакам. Например: *покажи договоры с компанией X, подписанные в этом году*.
    -	**Просмотр данных записи** — все атрибуты, статус, ответственный, связанные объекты.
    -	**Работа с документами внутри записи** — чтение текста прикреплённого файла, просмотр истории версий (кто и когда менял).
    -	**Анализ документа** — не просто чтение, а содержательный ответ на вопрос по документу (о чём он, какие условия, есть ли риски и т.п.).
    -	**Связанные контакты** — кто участвует в сделке или обращении.
    -	**История активности по записи** — комментарии, звонки, письма, встречи, поручения.
    -	**Создание и изменение записей** — например, создание новой записи или обновление её полей. Это чувствительное действие, поэтому система всегда запрашивает подтверждение перед изменением.
    -	**Удаление записей** — только с подтверждением и не более 10 штук за раз (защита от случайного массового удаления).
    -	**Семантический поиск** (если включена такая возможность) — поиск документов и записей по смыслу запроса, а не по точному совпадению слов.


Работа с задачами
""""""""""""""""""

.. _AI_tasks_work:

Отдельного «модуля задач» в привычном понимании (список задач, кнопка «завершить задачу», комментарии к задаче) в системе нет — задачи в Citeck технически являются записями особого типа, поэтому:

    -	**Поиск задач** — так же, как поиск любых записей. Например: *покажи мои открытые задачи* или *найди задачи со словом "проверка" в названии*.
    -	**Завершение задачи или смена статуса** — тем же способом, что и изменение любой записи: ассистент меняет статус задачи на «выполнено» (с подтверждением).
    -	**Поручения и задачи, связанные с записью** — видны в истории активности документа или клиента, к которому они относятся.

Работа с контентом
~~~~~~~~~~~~~~~~~~~~~~

Редактирование текста
""""""""""""""""""""""""

Помощник по редактированию текста имеет 2 функции:

    - **редактирование любого атрибута** документа;
    - **интеграция с редактором Lexical**.

Помощник позволяет писать новые статьи, редактировать их, изменять текущий текст, улучшать описание задач, улучшать заголовки и прочее для работы с текстом.

Доступны быстрые действия над выделенным текстом: **улучшить**, **упростить**, **расширить**, **резюмировать**, **исправить грамматику**, **формализовать**, **перевести** — а также произвольная правка свободным текстовым запросом. Правка скриптов, в отличие от текста, обслуживается агентом конфигурирования платформы — со своими быстрыми действиями (объяснить, исправить, оптимизировать) и доступом к метаданным типов.


Редактирование текстовых атрибутов документа
**********************************************

Например, улучшим **заголовок задачи** **(1)**.

Вызовем **ассистента** **(2)** и попросим его сгенерировать более понятный заголовок. Результат будет выдан в виде **diff-view** (наглядные различия между двумя наборами данных) **(3)**. При нажатии кнопки **Применить изменения** **(4)** будет отправлен update-запрос на изменение заголовка.

В редакторе необходимо вызвать ассистент и попросить его, например, изменить стиль статьи, что-то добавить или изменить:

.. image:: _static/AI_Assistant/lexical_02.png
    :width: 700

Результат так же будет выдан в виде **diff-view** **(1)**, где показано что конкретно было изменено. В данном режиме работы при нажатии кнопки **Применить изменения** **(2)** текст сразу подставляется в текущий редактор, чтобы его можно было дальше подредактировать, изменить и уже потом сохранить статью.

Работа с файлами в чате
""""""""""""""""""""""""""""""""""""

Файл можно загрузить прямо в диалог с ассистентом — без предварительного создания записи:

    - **Анализ загруженного файла** - изображения анализируются по содержимому напрямую; PDF — напрямую, если модель агента поддерживает нативное чтение PDF (например, Anthropic Claude), иначе через извлечённый текст; офисные форматы (DOCX, XLSX) — через извлечённый текст или PDF-превью платформы. Максимальный размер файла настраивается (по умолчанию 10 МБ)
    - **Сохранение результата в запись** - когда ассистент создаёт или обрабатывает файл, в чате появляется карточка сохранения с выбором: заменить основной контент текущей записи, записать в её атрибут, создать новую запись (размещается в папке «Сгенерировано ИИ») — или отменить
    - **Несколько файлов одновременно** - каждый ожидающий файл имеет собственную карточку с кнопками; неподтверждённый файл автоматически удаляется через 30 минут

**Запросы:**

    * *Проанализируй этот файл* (с приложенным документом)
    * *Извлеки из счёта сумму и поставщика*
    * *Переведи документ и сохрани результат в новую запись*

Анализ и сравнение документов
""""""""""""""""""""""""""""""""""""

    -	**Анализ документов** на основе их атрибутов и содержимого
    -	**Сравнение версий** документов, выделение изменений и юридических аспектов
    -	**Ответы на вопросы** по документам
    -	Возможность **указывать в контекст** несколько документов с одним типом данных

**Запросы (анализ документа):**

    * *Расскажи кратко, о чем этот договор?*
    * *Есть ли пункты, которые нарушают права сторон?*
    * *Предложи улучшения*

**Запросы (сравнение документов):**

    * *В чем разница атрибутов договора @запись и @договор №4? Составь итоговую таблицу с различиями*

**Запросы (сравнение версий):**

    * *Какие были изменения в последней версии договора @запись?*

Генерация изображений
"""""""""""""""""""""""

Поставляемый агент «Помощник по изображениям» генерирует и редактирует изображения прямо в чате:

    - **Генерация по описанию** - создание изображения с нуля по текстовому запросу
    - **Итеративное редактирование** - правки только что сгенерированного или загруженного изображения в том же диалоге: «убери фон», «сделай ярче», «добавь текст»
    - **Параметры** - формат (квадрат, портрет, альбом), качество (черновик, стандарт, лучшее), прозрачный фон для иконок
    - **Анализ изображений** - описание содержимого загруженной картинки
    - **Сохранение** - результат сохраняется в запись через карточку сохранения файла (см. «Работа с файлами в чате»)

Доступ к генерации изображений управляется отдельной группой ``ai-image-allowed`` — дополнительно к общей группе AI-функций. На один диалог действует лимит в 20 генераций; для продолжения работы откройте новый чат.

**Запросы:**

    * *Нарисуй иконку для раздела «Командировки»*
    * *Сделай баннер к письму о новогодних скидках*
    * *Убери фон и сделай его прозрачным*
    * *Что изображено на этой картинке?*


Поиск и аналитика
~~~~~~~~~~~~~~~~~~~~~~

Поиск по документам
"""""""""""""""""""""""

Семантический поиск по смыслу запроса, а не по точному совпадению слов. Например: *найди все договоры с компанией X, которые были подписаны в этом году и содержат условие о штрафах*.

Клиент 360
"""""""""""""""""""""""

.. _AI_client_360:

Комплексный анализ клиентов и контрагентов: сделки, заказы, платежи, договоры, обращения в поддержку, история активности — всё собирается в единый отчёт.

    - **Комплексный анализ клиентов** - полная картина взаимодействий с контрагентами
    - **Анализ сделок** - статусы, суммы, успешность, тенденции развития
    - **Обзор заказов** - частота, объемы, предпочтения продуктов
    - **История платежей** - анализ платежной дисциплины и сумм
    - **Оценка взаимоотношений** - здоровье бизнес-отношений и возможности роста
    - **Анализ обращений в техподдержку** - контроль SLA и выявление проблем
