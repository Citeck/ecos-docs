Управление проектами
======================

**Project tracker** - инструмент для управления проектами, организации рабочих процессов команд, мониторинга задач. **Project tracker** обеспечивает:

  - создание отдельных проектов;
  - планирование спринтов;
  - ведение бэклога задач;
  - постановку задач и отслеживание их статуса в текущем спринте на канбан-доске;
  - учет времени работы над задачами.

.. _ept_integrations:

Интеграция с GitLab и Jira
---------------------------

Project tracker можно связать с внешними системами с помощью :ref:`Camel DSL<camel_dsl_overview>`:

- **GitLab** — коммиты и запросы на слияние (MR) автоматически отображаются в карточках задач проекта. Связь устанавливается по ключу задачи Project tracker, указанному в комментарии к коммиту или в названии MR. См. :ref:`Настройки синхронизации Commits и Мerge requests<ept_gitlab_sync>`.
- **Jira** — перенос проекта из Jira в Project tracker: задачи, комментарии, затраченное время, компоненты, теги, релизы, спринты, вложения и связи между задачами. См. :ref:`Настройка импорта задач из Jira<ept_jira_import>`.

Подробно о настройке см. :ref:`Настройка импорта проектов из Jira<camel_dsl_jira_import>`.
