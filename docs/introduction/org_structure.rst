.. _org_structure:

Организационная структура
===========================

.. contents::
   :depth: 4

Раздел описывает работу с организационной структурой в Citeck: просмотр иерархии подразделений и сотрудников, создание групп и пользователей, редактирование профилей, а также настройку компонента **Оргструктура**, используемого в формах и бизнес-процессах.

Страница оргструктуры
----------------------

**Организационная структура** – система иерархически упорядоченных организационных единиц (должностей, отделов, подразделений). Она используется для назначения исполнителей в бизнес-процессах, настройки прав доступа, управления задачами и делегирования полномочий.

.. note::

 Оргструктура доступна в рабочем пространстве :ref:`Справочники<datalists>` и на :ref:`корпоративном портале<corp_portal>`.

Форма оргструктуры разделена на две части и содержит:

 - иерархическое дерево структуры с возможностью поиска **(1)**,
 - дашборд с информацией о выбранном подразделении или пользователе **(2)**: состав группы, список участников, контактные данные.

Компонент Оргструктура
------------------------

Компонент используется для выбора сотрудников и групп в формах документов, бизнес-процессов и других местах системы, где требуется указать исполнителя, ответственного или участника.

.. image:: _static/org_structure/org_s_1.png
       :width: 600
       :align: center

В типовой настройке оргструктура представлена вкладками **(1)**: **По уровням** и **Все пользователи**. Воспользуйтесь строкой поиска при необходимости **(2)**.

Вкладка **По уровням** открывается по умолчанию, но в настройках компонента формы можно выбрать другую начальную вкладку или скрыть переключатель. **Все пользователи** доступна, если разрешён выбор пользователей; при разрешённом выборе ролей также может отображаться вкладка ролей.

По уровням
~~~~~~~~~~~

Выберите сотрудника, нажав на **(3)**:

По умолчанию текстовый поиск ограничен корневой группой компонента и её иерархией. Настройка компонента **Search in all groups** позволяет искать по всем группам. Без поискового текста дерево показывает непосредственных участников раскрываемой группы.

.. image:: _static/org_structure/org_s_2.png
       :width: 400
       :align: center

Все пользователи
~~~~~~~~~~~~~~~~~~

При включённых рабочих пространствах вкладка **Все пользователи** по умолчанию показывает пользователей текущего пространства. Настройка компонента **Display all users of the system** снимает это ограничение области поиска; серверные права доступа продолжают действовать.

.. image:: _static/org_structure/org_s_3.png
       :width: 400
       :align: center

Неактивные пользователи, если они не скрыты настройками, отображаются с пониженной непрозрачностью.

Конфигурация компонента оргструктуры
-------------------------------------

.. _orgstructure_config:

Перейдите в журнал :ref:`«Конфигурация ECOS»<configuration_admin>`.

Журнал доступен по адресу: ``v2/journals?journalId=ecos-configs&viewMode=table&ws=admin$workspace``

В поисковой строке введите **org** для поиска настроек оргструктуры. Настройку ``hide-disabled-users-for-everyone`` найдите отдельно по её идентификатору:

.. list-table::
      :widths: 45 55
      :header-rows: 1
      :align: center
      :class: tight-table

      * - Идентификатор
        - Описание
      * - ``orgstruct-username-mask``
        - Маска отображения имени пользователя в компоненте Оргструктура
      * - ``hide-in-orgstruct``
        - Список идентификаторов пользователей/групп, исключаемых из выдачи дерева и списка пользователей, в том числе без поискового текста
      * - ``hide-disabled-users-for-everyone``
        - Скрыть отключённых пользователей для всех, включая администраторов. Имеет приоритет над следующей настройкой
      * - ``orgstruct-show-inactive-user-only-for-admin``
        - Скрыть неактивных пользователей для всех, кроме администраторов
      * - ``orgstruct-search-user-extra-fields``
        - Дополнительные атрибуты для поиска пользователей
      * - ``orgstruct-search-user-middle-name``
        - Включить поиск пользователей по отчеству

       :width: 700
       :align: center

Изменение маски вывода данных пользователя
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. note::

    Маска задаётся централизованно и используется при отображении пользователей в списке выбора компонента Оргструктура. Отдельные представления могут использовать собственные подписи или не применять маску.

Маску для отображения информации о пользователе можно изменить. Откройте идентификатор **orgstruct-username-mask** в режиме редактирования:

.. image:: _static/org_structure/mask_1.png
       :width: 600
       :align: center

Укажите маску, например, **${firstName} ${lastName} ${email}** и сохраните:

.. image:: _static/org_structure/mask_2.png
       :width: 400
       :align: center

Измененный вывод данных пользователя в компоненте Оргструктура:

.. image:: _static/org_structure/mask_3.png
       :width: 400
       :align: center

Добавлена возможность в конфигурации маски отображения пользователей в компоненте оргструктура использовать код HTML. 

Пример с использованием кода HTML. Маска:

.. code-block:: html

   ${firstName} ${lastName} <a style="color: #7396cd;" href="/v2/orgstructure?recordRef=emodel/person@${fullName}" target="_blank" rel="noopener noreferrer"><b>(${fullName})</b></a>

.. image:: _static/org_structure/mask_4.png
       :width: 400
       :align: center

По клику на ссылку в отдельной вкладке открывается страница профиля пользователя.

Часто используемые атрибуты для маски:

В контексте этого компонента ``fullName`` содержит системное имя пользователя (``authorityName``). Значение одноимённого поля в других API может отличаться.

.. list-table::
      :widths: 30 70
      :header-rows: 1
      :align: center
      :class: tight-table

      * - Атрибут
        - Описание
      * - ``${firstName}``
        - Имя пользователя
      * - ``${lastName}``
        - Фамилия пользователя
      * - ``${middleName}``
        - Отчество пользователя
      * - ``${fullName}``
        - Системное имя (логин)
      * - ``${email}``
        - Электронная почта

Скрывать пользователей/ группы при поиске в оргструктуре
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Определённых пользователей или группы можно исключить из выдачи дерева и списка пользователей оргструктуры, в том числе без введённого поискового текста. Эта настройка не является запретом доступа к записи.

Откройте идентификатор **hide-in-orgstruct** в режиме редактирования. Укажите логины пользователей, например, **ivanov_ii,petrov_vv** и сохраните:

.. image:: _static/org_structure/hide_2.png
       :width: 400
       :align: center

Поиск пользователя в компоненте **Оргструктура**:

.. image:: _static/org_structure/hide_3.png
       :width: 400
       :align: center

Скрывать отключенных пользователей для всех, кроме администраторов
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

В оргструктуре отключённых пользователей можно скрыть для всех, кроме администраторов, если выключена настройка **hide-disabled-users-for-everyone**. При включённой **hide-disabled-users-for-everyone** они скрыты и от администраторов независимо от значения **orgstruct-show-inactive-user-only-for-admin**.

Клиентские значения по умолчанию: **hide-disabled-users-for-everyone** включена, **orgstruct-show-inactive-user-only-for-admin** выключена. На стенде эти значения могут быть переопределены.

Откройте идентификатор **orgstruct-show-inactive-user-only-for-admin** в режиме редактирования:

.. image:: _static/org_structure/turned_off_user.png
       :width: 400
       :align: center

Установите флаг **«Включить»**.

Дополнительные поля для поиска пользователей
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Алгоритм поиска пользователей зависит от количества слов:

       * **1 слово** — по отображаемому имени и системному идентификатору, а также дополнительным настроенным полям;

              .. image:: _static/org_structure/search_defalt.png
                     :width: 300
                     :align: center

       * **2 слова** — по сочетаниям имени, фамилии и отчества с перестановкой слов, а также по полной строке в одном из полей ФИО;
       * **3 слова** — по имени, фамилии и отчеству с перестановками и вариантами составных частей ФИО;
       * **4 слова и более** — по полной строке и строке с обратным порядком слов в базовых и дополнительных полях.

Для двух и трёх слов используются специальные правила по полям ФИО: дополнительные поля не расширяют эти ветки поиска.

Для добавления дополнительных полей для поиска откройте идентификатор **orgstruct-search-user-extra-fields** в режиме редактирования:

.. image:: _static/org_structure/add_field_search.png
       :width: 400
       :align: center

Укажите наименование :ref:`атрибута<org_structure_type_person>`, по которому необходимо искать. Несколько имён можно перечислить через запятую в одном значении настройки.

Поиск по добавленному в настройку полю:

.. image:: _static/org_structure/other_field_search.png
       :width: 600
       :align: center

Использовать Отчество для поиска пользователей
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Чтобы добавить отчество в общий набор поисковых полей, откройте идентификатор **orgstruct-search-user-middle-name** в режиме редактирования. Это влияет на поиск по одному слову и по четырём и более словам; специальные правила для двух и трёх слов уже учитывают отчество независимо от флага.
