.. _select_ws:

Выбор рабочего пространства
============================

.. contents::
   :depth: 2

В левом верхнем углу доступна кнопка для выбора рабочих пространств и создания нового:

 .. image:: _static/01_button_select_00.png
       :width: 700
       :align: center

В выпадающем списке отображаются наиболее часто используемые пространства **(1)**. Остальные пространства, к которым у вас есть доступ, и публичные, к которым можно присоединиться, доступны по нажатию **Посмотреть больше (2)** — откроется общее меню рабочих пространств:

      - **Мои пространства** — пространства, участником которых вы являетесь:

      .. image:: _static/01_button_select_01.png
            :width: 700
            :align: center

      - **Публичные пространства** — открытые пространства, к которым можно присоединиться:

      .. image:: _static/01_button_select_02.png
            :width: 700
            :align: center

При повторном открытии общего меню рабочих пространств будет открываться вкладка **Мои пространства**.

Для присоединения к пространству нажмите:

 .. image:: _static/01_button_select_03.png
       :width: 600
       :align: center

Подтвердите выбор:

 .. image:: _static/01_button_select_04.png
       :width: 400
       :align: center

После подтверждения откроется выбранное пространство. При переключении может восстановиться его последняя активная вкладка. Если сохранённой вкладки нет, используется настроенная домашняя страница или дашборд. Общий вид рабочего пространства:

 .. image:: _static/wp_overview.png
       :width: 700
       :align: center

**1** — Переход к домашней странице рабочего пространства. См. :ref:`настройку домашней страницы<workspace_settings>`.

**2** — Разделы рабочего пространства (навигационное меню).

.. _ws_actions:

Доступные действия с рабочими пространствами
---------------------------------------------

.. grid:: 2
   :gutter: 2

   .. grid-item::

      .. image:: _static/actions.png
         :width: 500
         :align: left

   .. grid-item::

      .. image:: _static/actions_1.png
         :width: 500
         :align: left


1. Пользователь **не является** участником публичного пространства — доступно действие **Присоединиться**.
2. Пользователю-участнику доступен переход в пространство. Действие **Выйти из пространства** в карточке показывается при прямом членстве. Если доступ предоставлен только через группу, самостоятельный выход не исключает пользователя из этой группы; состав участников меняет менеджер.
3. Если текущий пользователь является единственным менеджером публичного или приватного пространства, при попытке выйти отображается сообщение:

   **«Вы не можете покинуть пространство, так как являетесь единственным менеджером»**:

 .. image:: _static/actions_2.png
       :width: 700
       :align: center

4. Менеджеру доступно удаление несистемного пространства при наличии соответствующего разрешения. Системные пространства защищены от удаления:

 .. image:: _static/actions_3.png
       :width: 700
       :align: center

Если пользователь переходит в публичное пространство по прямой ссылке, не являясь его участником, отображается предложение: присоединиться к рабочему пространству или вернуться в личное пространство.

 .. image:: _static/actions_4.png
       :width: 700
       :align: center

Если пользователь переходит в приватное пространство по прямой ссылке, не являясь его участником, отображается предложение: вернуться в личное пространство.

 .. image:: _static/actions_5.png
       :width: 700
       :align: center


.. _ws_user_select:

Выбор пользователей в рабочем пространстве
--------------------------------------------

При включённых рабочих пространствах список **«Все пользователи»** по умолчанию фильтруется по текущему пространству. Результат также зависит от поиска и настроек скрытия/отключения пользователей. Настройка компонента **«Отображать всех пользователей системы»** отключает ограничение текущим пространством:

 .. image:: _static/users.png
       :width: 400
       :align: center


.. _ws_notifications:

Уведомления
------------

При добавлении и исключении участников предусмотрены уведомления по электронной почте. Получатели определяются из пользователей и групп с непустым email; внешние пользователи исключаются. Доставка зависит от настройки сервиса уведомлений и почты.

Самостоятельное вступление не сопровождается письмом о добавлении участника. При самостоятельном выходе письмо не отправляется, если удаляется запись вступления или создателя, содержащая только текущего пользователя. Для добавления записи создателя и изменений при развёртывании пространства также предусмотрены исключения, поэтому письмо не сопровождает каждое действие.
