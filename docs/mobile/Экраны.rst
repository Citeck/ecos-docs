.. _mobile-screens-lang:

Язык
~~~~~~~~

* локаль передаётся в заголовках запросов к API ``src/services/api.service.ts``
* при парсинге форм выбираются лейблы, соответствующие текущей локали
* при регистрации и обновлении токена пуш-уведомлений вместе с токеном передаётся используемая локаль

См. :ref:`mobile-push`
